# 📖 Overview

This project demonstrates a wide range of data visualization techniques used in Data Science and Machine Learning. It covers plotting with **Matplotlib**, statistical visualizations with **Seaborn**, and interactive charts with **Plotly/Cufflinks**.

The project includes examples of line plots, subplots, object-oriented plotting, image visualization, distribution plots, categorical plots, matrix plots, correlation heatmaps, regression plots, and interactive visualizations. It serves as a practical reference for performing Exploratory Data Analysis (EDA) and presenting data effectively.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/ACUTE02/Python-Data-Visualization.git
```

```bash
cd Python-Data-Visualization
```

---

## Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

### Linux/macOS

```bash
python3 -m venv venv
```

Activate

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

or

```bash
pip install numpy pandas matplotlib seaborn plotly cufflinks
```
